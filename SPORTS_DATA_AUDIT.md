## 0. Короткий вывод

- **Выдуманных данных на сайте нет.** Все 6273 матча в базе пришли из OddsPapi (`matches.source = 'oddspapi'`). Записей `demo` и `manual` — 0. Тестовые аккаунты из `supabase/seed.sql` применяются только локально (README, раздел «Подключение Supabase Cloud»: «seed.sql в облако НЕ применяется»).
- **Фактически работают четыре внешних источника:**
  - OddsPapi (бесплатный план) — расписание и линии;
  - NHL API — результаты, live, фото, логотипы;
  - OpenDota — результаты Dota 2;
  - Wikidata/Commons и TheSportsDB — логотипы и фото.
- **API-Football подключён в коде, но не работает.** Аккаунт заблокирован, ключа в Supabase Secrets нет. Из-за этого не работают футбольные результаты, live и собственные линии.
- **Главный риск — не цена, а условия использования.**
  - Условия NHL.com разрешают только «non-commercial, informational, personal use» и запрещают автоматический сбор данных и использование логотипов без письменного согласия. На NHL API держатся расчёт купонов НХЛ, live, фото и логотипы.
  - Условия PandaScore и Liquipedia прямо исключают проекты со ставками и фэнтези.
- **Минимальный бюджет для полного футбола — $19 в месяц** (API-Football Pro: все 6 лиг главной, включая РПЛ, текущий сезон, статистика игроков).
- **Рекомендуемый бюджет — около $70–110 в месяц.** Точная цена API-Hockey и API-Basketball не подтверждена: см. таблицу №4.

## 1. Текущее состояние проекта

### 1.1 Как устроен сбор данных ✅

| Компонент | Где | Что делает |
|---|---|---|
| Edge Function `sports-sync` | `supabase/functions/sports-sync/index.ts` | Единственная точка обращения к внешним API: расписание, линии, результаты, логотипы, фото. Вызывается pg_cron |
| Edge Function `live-match` | `supabase/functions/live-match/index.ts` | Live-снимок матча. Ответы кэшируются в `provider_cache`: к провайдеру уходит не больше одного запроса за TTL при любом числе зрителей (НХЛ — 15 с, футбол — 3 мин) |
| pg_cron | `supabase/migrations/20261017001000_platform.sql`, `…001900_team_logos.sql`, `20261018000100_player_photos.sql` | `pickup-sports-sync` каждые 15 мин, `pickup-team-logos` и `pickup-player-photos` каждые 10 мин |
| Хранение | таблицы `matches`, `teams`, `players`, `projections`, `player_statistics`, `provider_cache`, `sync_runs` | Все посетители читают общие данные из базы через RLS. Внешние API из браузера не вызываются |
| Ключи | Supabase Secrets | Во фронтенде только `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` (`.env.example`, поиск по `src/`) — это публичные ключи |

## 4. Оптимизация расходов и архитектура

Уже есть: централизованный сбор в Edge Functions, кэш `provider_cache`, общие данные в базе для всех посетителей, ключи только в Supabase Secrets, разная частота обновления (расписание раз в 12 ч, линии и результаты каждые 15 мин, live — по TTL 15 с или 3 мин, логотипы и фото — партиями раз в 10 мин).

Что добавить:

1. **Линии PICKUP вместо покупки линий букмекеров.** Сайт работает на виртуальных рублях, поэтому линии не обязаны приходить от букмекеров. Движок `supabase/functions/_shared/house-lines/engine.ts` считает линию по форме игрока. Тогда платить нужно только за статистику: она нужна и для линий, и для расчёта.
2. **Цепочки резервных источников по видам спорта.** Если основной источник недоступен, берётся резервный, а если подходящего нет, матч уходит на ручную проверку:
   - НХЛ: BDL → NHL API;
   - футбол: API-Football → football-data.org (только счёт);
   - Dota 2: OpenDota → BDL.

   Перед включением нужно проверить, что условия каждого источника это разрешают.
3. **Частота по состоянию матча:**
   - расписание раз в 6–12 ч;
   - результаты — только для матчей, начавшихся более 100 минут назад (так уже сделано: `matches_awaiting_external_results`);
   - live — только для матчей со статусом LIVE и только пока кто-то смотрит (так уже сделано через TTL `live-match`).
4. **Бюджет запросов.** На каждый платный источник — отдельный счётчик в `sync_runs` и остановка до исчерпания лимита (сейчас так сделано только для OddsPapi: `ODDSPAPI_MAX_REQUESTS`).
5. **Скрывать то, чего нет.** Уже сделано: «Линий на этот матч нет», пустые турниры не показываются, «Открытых линий сейчас нет».

## 5. Итог

**Оставить**
- OddsPapi Free — расписание всех видов спорта.
- OpenDota — результаты Dota 2.
- Wikimedia Commons и Wikidata — логотипы и фото со свободными лицензиями и атрибуцией.
- TheSportsDB — логотипы, после проверки условий.
- Централизованную архитектуру `sports-sync`, `live-match`, `provider_cache`, pg_cron.

**Заменить или пересмотреть**
- NHL API для результатов, live, фото и логотипов — юридически рискованный источник для коммерческого сайта ([условия NHL.com](https://www.nhl.com/info/terms-of-service)). Для коммерческого запуска заменить на BALLDONTLIE NHL ($9.99) или получить разрешение NHL. Эмблемы и фото НХЛ без согласия NHL не использовать.
- Фото НБА с `cdn.nba.com` — условия ❓. Без разрешения лучше показывать фото только с Commons.

**Подключить новые бесплатные источники:** серьёзных легальных бесплатных источников статистики, кроме уже подключённых, не нашлось. football-data.org Free можно добавить как резервный источник счёта футбольных матчей, но не для расчёта.

**Бесплатно получить невозможно**
- Статистика игроков футбола в текущем сезоне.
- Статистика КХЛ и Лиги ВТБ.
- Статистика CS2 с разрешением для фэнтези.
- Линии букмекеров на игроков в нужном объёме (бесплатный OddsPapi — 250 запросов).

**За что действительно стоит платить**
1. **API-Football Pro, $19 в месяц** — самый дешёвый способ закрыть все 6 футбольных лиг главной, включая РПЛ. Перед оплатой выяснить причину блокировки и проверить условия о фэнтези.
2. **BALLDONTLIE** — дёшево, $9.99 за НБА и НХЛ, и единственный найденный поставщик, который прямо разрешает фэнтези-использование. CS2 и ВТБ стоят дороже, $39.99 каждый, — подключать по мере необходимости.
3. Линии букмекеров покупать не обязательно: собственные линии PICKUP по статистике дешевле.

**Минимальная сумма для максимально полных данных.** Полное покрытие всех 5 видов спорта и 10 лиг главной со статистикой для расчёта — **около $137–157 в месяц** (вариант «Рекомендуемый + киберспорт и ВТБ»). Без CS2 и ВТБ — **около $57–77**. Только футбол — **$19**.
